GUIDE / HOW IT WORKS

三步，让旧教程跟上新版本。

AI 时代只要学得够慢，那就不用学了——所以先查清楚再学。

01

连接元宝搜索

「API 设置」里二选一：服务 API Key（推荐）或腾讯云 SecretId + SecretKey。点「测试并使用」会真实发起 1 次最小搜索，只有成功才显示「已连接」。

02

检测一篇教程

粘贴链接，或直接粘贴教程里的版本号 / 安装命令（更准）。CodeFresh 比对 GitHub 官方 Release 与 Changelog，给出四种结论：仍可参考 / 建议复核 / 有明确过期证据 / 证据不足。

03

追踪版本 · 发现教程

版本雷达直接读取 openclaw/openclaw 官方发布记录，稳定版和 beta 分开显示；发现页用元宝搜索找近期教程，CSDN 标签只给真实来自 csdn.net 的结果。

  • 元宝搜索
  • GitHub 版本对比体检
  • 版本雷达 / Changelog

安全与诚实

  • 密钥只存在本页内存，刷新即清空；不写 localStorage / Cookie / URL / 日志。
  • 不伪造版本号、热度、阅读量或剩余额度；没有日期就显示「未知」。
  • 示例报告始终标注「示例数据」。
